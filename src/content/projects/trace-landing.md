## Overview

Trace is a next-generation distributed telemetry platform that ingests millions of spans per second using zero-overhead eBPF kernel probes and sub-millisecond ClickHouse columnar storage.

## Key Features

- **Distributed Root-Cause Graph Visualizer**: Interactive microservice topology highlighting upstream bottlenecks and downstream error cascades.
- **ClickHouse Columnar Query Simulator**: Real-time P99 latency meters demonstrating sub-millisecond query retrieval over billions of spans.
- **TCO & Cloud Cost Reduction Calculator**: Dynamic ROI modeler showing up to 90% savings compared to legacy APM vendors (Datadog, Dynatrace).
- **One-liner Deployment Snippet Switcher**: Copyable Helm, DaemonSet, and Docker Compose snippets for instant cluster instrumentation.
- **Comprehensive SEO & PWA**: Dynamic manifest, sitemaps, robots.txt, and responsive SVG icons.

## Technical Architecture

Built with Next.js 15 App Router, React 19, Tailwind CSS v4, and OpenTelemetry standards. Deployed on Vercel Edge with continuous delivery and live performance metrics.
