## Overview

FreshCart is a hyper-local grocery delivery platform connecting households with organic growers within a 40-mile radius, guaranteeing zero single-use plastic and 30-minute doorstep fulfillment.

## Key Features

- **Interactive Product Catalog**: Instant search, dietary filtering (Produce, Dairy, Bakery, Pantry), and real-time quantity modifiers.
- **Dynamic Slide-Over Cart Drawer**: Live checkout calculation, item removal, and an animated "$35 Free Delivery" progress meter.
- **Farm Origin Traceability**: Detailed farm-to-table provenance badges showing grower location, harvesting times, and organic certifications.
- **Delivery Slot Reservation**: Real-time delivery time-slot selector and postal code availability engine.
- **Complete Legal Subpages**: Accessible dedicated routes for `/privacy`, `/terms`, `/accessibility`, and `/cookies`.

## Technical Architecture

Built with modern React and Tailwind CSS, featuring SVG displacement glassmorphism, responsive mobile-first viewports, full PWA manifest, and Vercel continuous deployment.
