## Overview

CoverDrive Cricket is a high-performance sports technology web platform built for professional cricketers, academies, and coaches. It translates biomechanical telemetry into an interactive, visual training experience.

## Key Features

- **Interactive 22-Yard Pitch Trajectory Simulation**: Live visualizer comparing release angles, seam movement, and landing zones across Express Pace, Off-Spin, and Leg-Spin.
- **Bat Swing Telemetry & Sweet-Spot Radar**: Real-time velocity meters, bat face angle indicators, and sweet-spot impact heatmaps.
- **Dynamic Tuition & Schedule Calculator**: Instant fee calculation based on age group (U-14, U-19, Senior Pro) and weekly training load.
- **Trial Session Booking Drawer**: Seamless slide-over reservation flow with instant schedule slot confirmation.
- **PWA & Performance Standards**: Native SVG favicon, dynamic sitemaps, robots.txt, and complete OpenGraph/Twitter social sharing cards.

## Technical Architecture

Built with Next.js 15 App Router, React 19 concurrent features, Tailwind CSS v4, and Framer Motion spring physics. Continuously deployed to Vercel Edge with zero-downtime Git webhooks and privacy-compliant `@vercel/analytics`.
