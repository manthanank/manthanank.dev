## Overview

Landing Forge is a developer-first scaffolding suite and template engine that generates accessible, high-performance, and high-converting Next.js landing pages across SaaS, AI, SportsTech, and E-Commerce domains.

## Key Features

- **Multi-Domain Preset Archetypes**: Six battle-tested design presets with tailored color palettes, typography scales, and interactive widgets.
- **Instant Typography & Token Transformer**: Automatic font pairing and color token compilation using Tailwind CSS v4 variables.
- **Copyable Section Primitives**: Reusable bento grids, comparison matrices, pricing tables, and hero layouts.
- **Lighthouse 100/100 Standards**: Optimized asset delivery, sub-75 kB first-load bundles, and zero layout shift.
- **Automated Vercel Deployment**: Continuous integration configured with native Git webhooks and Vercel Web Analytics.

## Technical Architecture

Engineered with Next.js 15, React 19, Tailwind CSS v4, and Framer Motion. Configured with strict TypeScript validation, dynamic sitemaps, robots.txt, and Web App Manifests.
