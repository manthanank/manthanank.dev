## Overview

Aegis is an enterprise cloud defense platform designed for mission-critical infrastructure where microsecond delays or single credential leaks result in catastrophic damages.

## Key Features

- **Runtime Policy Compiler Simulation**: Interactive Cedar / Rego (OPA) policy sandbox that demonstrates real-time authorization checks and automated remediation rules.
- **Blast Radius & Threat Modeler**: Interactive multi-cloud workload risk evaluator measuring blast radius reduction across AWS, GCP, and Kubernetes clusters.
- **Security Architecture Topology**: Clickable system diagram mapping edge gateway inspection, identity broker tokens, and threat interception nodes.
- **Compliance Matrix**: Built-in verification mapping for SOC 2 Type II, ISO 27001, HIPAA, and FedRAMP frameworks.
- **Production Standards**: Full PWA support, dynamic robots.txt, sitemaps, and Vercel Analytics.

## Technical Architecture

Built with Next.js 15, React 19, Tailwind CSS v4, and strict TypeScript. Deployed on Vercel Edge with zero compile warnings and verified Git author identity pipelines.
