## Overview

Part of **TheLearningHubOrg** open-source curriculum, **Learn TypeScript** is an in-depth reference and hands-on guide covering TypeScript from modern fundamentals to advanced type-level programming ("type gymnastics").

## Key Curriculum Modules

- **Type System Fundamentals**: Primitive types, structural typing vs nominal typing, unions, intersections, and literal types.
- **Strict Mode Engineering**: Configuring `strictNullChecks`, `noImplicitAny`, `noUncheckedIndexedAccess`, and `exactOptionalPropertyTypes` for bulletproof enterprise codebases.
- **Generics & Utility Types**: Deep-dive into custom type utilities (`DeepReadonly`, `Flatten`, `NonNullableProperties`) and conditional types with `infer`.
- **Type Gymnastics**: Recursive types, template literal types, mapped types with key remapping, and tuple manipulation.
- **Framework Integration**: Typing React 19 hooks and server actions, Angular signals, and Node.js backend schemas (Zod, TypeBox).

## Open Source Impact

Maintained under **TheLearningHubOrg**, providing curated, battle-tested type patterns and interactive examples referenced by engineers worldwide.
